# TELUK SENJA — GTA6-01

[![GTA6-01](https://make.fun/badge/gta6-01.svg)](https://make.fun/bounty/gta6-01)
[![Rank](https://make.fun/badge/gta6-01/Iruwae/gta6-01-entry-r25/rank.svg)](https://make.fun/bounty/gta6-01)
[![Reward](https://make.fun/badge/gta6-01/Iruwae/gta6-01-entry-r25/reward.svg)](https://make.fun/bounty/gta6-01)

Game dunia terbuka di kota pesisir Teluk Senja saat matahari terbenam, dengan
render detail tinggi: pencahayaan dari peta lingkungan langit senja, material
PBR, tekstur foto di gedung dan toko, backdrop langit pantai hasil generate,
palem berlapis, bloom dan tone mapping filmik. Raka pulang ke kotanya dan harus
merebut hormat jalanan: delapan misi dalam tiga babak, balap pantai melewati
14 gerbang bercahaya di jalan tepi laut dikejar mobil polisi, sistem buron lima
bintang dan panel dispatch, tujuh senjata, kru, taksi, koleksi Koin Senja, dan
radio Senja 97.5.

Dibangun dengan Three.js dan DOM HUD, tanpa build step. Jalankan `node serve.ts`
lalu buka `http://127.0.0.1:8901/index.html`.
