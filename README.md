Open-world crime game di kota pesisir Indonesia saat senja. Raka pulang ke Teluk Senja: kejar gerbang balap di jalan pantai, lolos dari kejaran polisi, ngobrol sama warga, kumpulin hormat dan Koin Senja. Rendernya pakai peta lingkungan dari langit senja, material PBR, tekstur foto, palem berlapis, bloom dan tone mapping filmik.
Jalankan `node serve.ts` lalu buka `http://127.0.0.1:8901/index.html`.
